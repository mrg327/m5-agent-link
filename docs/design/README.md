# Design docs

One doc per feature or subsystem, written before or with the code and kept true after it ships
([docs.md](../conventions/docs.md) §2). A new one starts from
[templates/design-doc.md](../conventions/templates/design-doc.md) and is named `<NAME>.md` in upper case
with hyphens (structure.md S-NEW-07). Background research is in `docs/research/`.

The index below is generated from each doc's front matter (status, owner role, issue,
`last_reviewed`, `summary`) by `python3 scripts/check.d/doc_meta.py --write`; `scripts/check docs`
fails when it is out of date ([docs.md](../conventions/docs.md) DOC-8 – DOC-11). To change a row,
edit the doc's front matter, not this table. A doc's own `Status:` line, where it has one, gives
the detail (what is not yet verified on the device, for example).
