    How this page stays true

    Every colour, timing, UUID and message name here is generated from the source by atlas/tools/extract.py. Nothing is retyped by hand, so the page cannot drift from the code.

    When watch.kind is wasm, the screen is the real firmware UI core and LVGL compiled to WebAssembly, driven by a JS daemon speaking the real protocol.
