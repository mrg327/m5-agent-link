# agentlink-keys

The gesture-typing decoder (SHARK2) for the watch's round keyboard: it turns key geometry and touch
strokes or taps into ranked word candidates. Pure Rust, no dependencies, no IO. `agentlinkd` uses it
in `keys.rs`.

## Build and test

```sh
scripts/check daemon                                    # fmt, clippy -D warnings, cargo test --workspace
cargo test -p agentlink-keys                            # from daemon/: tests/gate.rs, the accuracy gate
cargo run --release -p agentlink-keys --example eval    # top-1 / top-4 accuracy and timing
```

| Path | Concern |
|---|---|
| `src/layout.rs` | Key geometry, packed key and point formats, the StopWatch QWERTY |
| `src/decode.rs`, `src/context.rs` | Templates, stroke and tap decoding, context vocabulary |
| `src/lexicon.rs` | The embedded word lists |
| `src/synth.rs`, `src/eval.rs` | Synthetic strokes and the evaluation behind the gate |
| `data/` | Word lists and their licence ([data/README.md](data/README.md)) |
| `tests/gate.rs` | Accuracy floor for synthetic strokes and taps |

## Rules that bind it

- S-CRATE-01 / RS-5: depends on no workspace crate. RS-26: no `unsafe`.
- `data/english.txt` is generated by `data/build_lexicon.py` from a SCOWL checkout that is not in the
  repo; do not edit it by hand.
