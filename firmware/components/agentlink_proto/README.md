# agentlink_proto

The C codec for the wire protocol, generated by zcbor 0.9.1 from
[`protocol/agentlink.cddl`](../../../protocol/agentlink.cddl), plus the vendored zcbor runtime. `core`
and the simulator link it. Semantics: [PROTOCOL.md](../../../docs/design/PROTOCOL.md).

## Build and test

```sh
firmware/components/agentlink_proto/regen.sh   # after any CDDL change (needs uv)
scripts/check sim                              # ctest protocol_vectors round-trips protocol/vectors
```

| Path | Concern |
|---|---|
| `src/agentlink_codec_{encode,decode}.c`, `include/agentlink_codec_{encode,decode,types}.h` | Generated codec. Do not edit. |
| `src/zcbor_*.c`, `include/zcbor_*.h` | Vendored zcbor runtime, copied by `regen.sh` |
| `patches/*.patch` | Upstream fixes applied to the runtime after copying |
| `regen.sh` | Pins zcbor 0.9.1 and `cbor2<5.7`, regenerates, copies, patches |
| `test/test_vectors.c` | Decodes and re-encodes every vector (ctest `protocol_vectors`) |
| `CMakeLists.txt` | ESP-IDF component, or a static library in the simulator; the encoder is built `ZCBOR_CANONICAL` |

## Rules that bind it

- S-DEP-04: includes only its own headers and the C library; never `core`, `hal.h` or LVGL.
- PROTO-26 / S-GEN-01: never edit the output by hand; commit the CDDL and the regenerated files
  together ([protocol.md](../../../docs/conventions/protocol.md)).
- The decoder rejects unknown keys and enum values, which is why the daemon gates new fields on the
  device's proto minor (PROTO-20).
